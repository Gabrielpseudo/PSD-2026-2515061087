Sistem Manajemen Data Buku Menggunakan Hash Map Open Addressing dengan Linear Probing

Program ini merupakan aplikasi sederhana berbasis Python yang digunakan untuk mengelola data buku pada sebuah perpustakaan atau toko buku. Program menyediakan beberapa fitur utama, yaitu menambahkan data buku, mencari buku berdasarkan kode buku, menghapus data buku, serta menampilkan seluruh isi data yang tersimpan di dalam hash table. Setiap buku memiliki kode buku sebagai identitas unik dan judul buku sebagai informasi utama yang disimpan.

Program diawali dengan pembuatan class SlotState yang berfungsi untuk mendefinisikan status setiap slot pada hash table. Terdapat tiga kondisi yang digunakan, yaitu EMPTY untuk menandai slot yang belum pernah digunakan, OCCUPIED untuk menunjukkan bahwa slot berisi data, dan DELETED untuk menandai bahwa data pada slot tersebut telah dihapus. Status ini sangat penting karena pada metode Open Addressing, slot yang dihapus tidak boleh langsung dianggap kosong agar proses pencarian tetap berjalan dengan benar. Selanjutnya dibuat class Entry yang digunakan sebagai wadah penyimpanan data pada setiap slot hash table. Setiap objek Entry memiliki tiga atribut utama, yaitu key untuk menyimpan kode buku, value untuk menyimpan judul buku, dan state untuk menyimpan status slot. Ketika objek Entry pertama kali dibuat, nilai key dan value diisi dengan None, sedangkan state diatur menjadi EMPTY. Bagian utama program terdapat pada class HashMapOpenAddressing. Class ini bertanggung jawab mengelola seluruh operasi yang berkaitan dengan hash table. Pada konstruktor class ini, program menentukan ukuran hash table melalui variabel SIZE yang secara default bernilai 10. Setelah itu dibuat sebuah list yang berisi objek Entry sebanyak ukuran yang telah ditentukan. Dengan demikian, setiap indeks pada hash table sudah memiliki slot penyimpanan yang siap digunakan. Program kemudian memiliki fungsi hash_function yang digunakan untuk menghitung posisi penyimpanan data berdasarkan kode buku. Fungsi ini menggunakan operasi modulus terhadap ukuran hash table. Hasil perhitungan tersebut akan menghasilkan indeks yang berada dalam rentang 0 hingga ukuran tabel dikurangi satu. Fungsi ini menjadi dasar utama dalam menentukan lokasi penyimpanan dan pencarian data. Proses penambahan data dilakukan melalui fungsi insert. Ketika pengguna memasukkan kode buku dan judul buku, program terlebih dahulu menghitung indeks awal menggunakan fungsi hash. Selanjutnya dibuat variabel first_deleted yang digunakan untuk menyimpan posisi slot yang sebelumnya pernah dihapus. Program kemudian melakukan proses pencarian slot menggunakan teknik Linear Probing. Jika slot yang diperiksa berstatus OCCUPIED, program akan mengecek apakah key yang ada sama dengan key yang akan dimasukkan. Jika sama, maka data lama akan diperbarui dengan data baru. Jika slot berstatus DELETED, posisi tersebut disimpan sebagai kandidat tempat penyimpanan. Namun jika ditemukan slot dengan status EMPTY, program langsung menyimpan data pada slot tersebut atau menggunakan slot DELETED pertama yang ditemukan sebelumnya. Setelah data berhasil disimpan, status slot diubah menjadi OCCUPIED. Untuk melakukan pencarian data, program menyediakan fungsi search. Fungsi ini menerima parameter berupa kode buku yang ingin dicari. Program menghitung indeks awal menggunakan fungsi hash kemudian melakukan penelusuran secara berurutan menggunakan Linear Probing. Jika ditemukan slot kosong (EMPTY), pencarian langsung dihentikan karena data dipastikan tidak ada di dalam hash table. Jika ditemukan slot yang berstatus OCCUPIED dan memiliki key yang sesuai, maka data tersebut dikembalikan sebagai hasil pencarian. Jika seluruh slot telah diperiksa namun data tidak ditemukan, fungsi akan mengembalikan nilai None. rogram juga memiliki fungsi remove_key yang digunakan untuk menghapus data buku berdasarkan kode buku. Fungsi ini pertama kali memanggil fungsi search untuk memastikan bahwa data yang akan dihapus benar-benar ada. Jika data ditemukan, status slot diubah menjadi DELETED. Teknik ini memungkinkan slot tetap dapat dilalui saat proses pencarian data lain yang mengalami collision. Jika data tidak ditemukan, fungsi akan mengembalikan nilai False. Selain proses tambah, cari, dan hapus data, program juga menyediakan fungsi display. Fungsi ini digunakan untuk menampilkan seluruh isi hash table beserta kondisi setiap slot. Program melakukan perulangan dari indeks pertama hingga indeks terakhir. Jika slot berstatus EMPTY, program menampilkan tulisan EMPTY. Jika slot berstatus DELETED, program menampilkan tulisan DELETED. Sedangkan jika slot berisi data, program menampilkan pasangan kode buku dan judul buku yang tersimpan pada slot tersebut. Fungsi ini sangat berguna untuk melihat bagaimana data ditempatkan di dalam hash table setelah terjadi collision maupun penghapusan data. Program juga memiliki fungsi menu yang digunakan untuk menampilkan daftar pilihan operasi kepada pengguna. Menu terdiri atas lima pilihan, yaitu menambahkan buku, mencari buku, menghapus buku, menampilkan seluruh buku, dan keluar dari program. Fungsi ini hanya berfungsi sebagai antarmuka sederhana yang memudahkan interaksi pengguna dengan sistem. Seluruh proses dijalankan melalui fungsi main. Pada awal fungsi ini dibuat objek HashMapOpenAddressing sebagai tempat penyimpanan data buku. Selanjutnya program menjalankan perulangan tanpa batas sehingga menu akan terus ditampilkan sampai pengguna memilih keluar dari program.
